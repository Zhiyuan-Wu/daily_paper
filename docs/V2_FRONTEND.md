# V2 Frontend

前端目录：`frontend/`

## 技术栈
- React + TypeScript + Vite
- Ant Design
- TanStack Query
- Zustand

## 本地运行
```bash
cd frontend
npm install
npm run dev
```

默认前端地址：`http://127.0.0.1:5173`

API 基地址环境变量：
- `VITE_API_BASE_URL`（默认 `http://127.0.0.1:8001`）

## 页面
- `/reports` 论文日报
- `/papers` 论文探索
- `/research` 深度调研
- `/recommendations` 推荐结果
- `/tasks` 任务中心
- `/settings` 设置

## 交互说明
- 全局布局：左侧功能侧边栏，右侧子页面内容。
- 论文日报：
  - 默认加载今天的日报。
  - 支持选择任意日期查看历史日报。
  - 若当天日报不存在，显示“生成今日日报”按钮。
  - 生成参数来自设置页“日报选项配置”卡片，不在日报页填写。
  - 点击生成后会创建异步任务并轮询任务状态，任务完成后自动刷新日报内容。
  - 默认参数：`arxiv + huggingface`，时间窗口 `7` 天，arXiv AI 分区（`cs.AI` 等）。
- 论文探索：
  - 展示数据库已有论文（表格）。
  - 第一列提供操作图标：查看详情、阅读全文（新标签打开 PDF）、喜欢（写入交互反馈）。
  - 阅读 PDF 按钮始终可点击，并标记状态：`本地PDF` / `需下载` / `PDF可能不可用`。
  - 其他列显示标题、时间、关键词。
- 深度调研：
  - 中央为 Google 风格输入框，用于创建新调研任务。
  - 右侧为历史任务面板（卡片列表），顶部提供“新的调研”按钮。
  - 选择历史任务后，中央展示对应调研报告。
- 设置：
  - 顶部展示系统状态（系统时间、论文数量、日报数量、任务数量、后端连通性）。
  - 同时展示论文源可用性（是否返回真实数据）。
  - 下方为可折叠配置卡片：日报选项、推荐算法参数、系统设置（含 LRU 等）。

## 注意
- 设置保存后立即生效（仅影响新任务）。
- 无本地 PDF 时，“阅读全文”会触发按需下载；若远端无 PDF，会在新标签页返回对应错误信息。
- 后端采用懒加载：列表阶段只拉取元信息，点击“阅读全文/详情”时会按需触发下载、解析与分析。
